# A2UI Basic Catalog in Storybook

An agent does not need a bespoke React screen for every task. It can **compose** a small, official vocabulary of
A2UI primitives into a full interface. This Storybook shows that vocabulary, one composition built from it, and how a
team can add its **own** primitives through our Storybook exporter.

## Two kinds of controls

- **Basic Catalog stories** use *preview controls*. Each one either maps 1:1 to an official A2UI property
  (category *A2UI properties*, described with the SDK's own schema text) or only sets up the demo
  (category *Preview setup*). Either way they build a message; they are not the SDK component's source props.
- **Exporter source primitives** (`StatusBadge`, `MetricLabel`, `ProgressIndicator`) are ordinary React components.
  Their controls come from TypeScript props via react-docgen, the same metadata the exporter converts.
