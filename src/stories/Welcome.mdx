## Where do these components come from?

The Basic Catalog components are supplied by the **official A2UI SDK**, not generated by our exporter.

- **`@a2ui/web_core`** contains the official Basic Catalog, processes A2UI messages, and supplies underlying web component implementations.
- **`@a2ui/react`** displays the processed A2UI surface inside a React application.
- **Storybook** provides interactive component previews and documentation; it doesn't invent or replace SDK components.
- **`createSurface`** is the JSON message describing component instances, their properties, and their layout relationships.

“Rendered by the official A2UI SDK” means the preview uses real SDK components rather than lookalikes.

## Where does the JSON come from?

| JSON | Source | Purpose |
| --- | --- | --- |
| Official Basic Catalog | `basicCatalog.toJson()` from `@a2ui/web_core` | Defines allowed component names and properties |
| Individual preview `createSurface` messages | Storybook story controls in this repository | Shows a concrete instance of an SDK component |
| November Budget `createSurface` | Deterministic sample logic adapted from our capstone showcase | Shows a complete interface composed from primitives |

**The budget Storybook example is not a live AI model call.** It uses deterministic sample logic for a reliable walkthrough.

The SDK also includes advanced catalog functions for binding, formatting, and validation. This introductory explorer focuses on components; the complete unmodified catalog remains available in the raw JSON view.

Our separate Storybook-to-A2UI exporter converts **new, source-authored React components** into additional A2UI catalog definitions. It remains available through the CLI but is intentionally outside this basic Storybook tour.
