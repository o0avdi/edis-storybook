# Building blocks for AI-assembled interfaces

An AI agent does not need a custom screen written for every task. Instead, it can pick from a set of ready-made
**building blocks** (text, cards, rows, buttons, sliders, text fields) and describe how to arrange them. This
Storybook shows those building blocks and one complete interface assembled from them: a personal budget tracker.

## Key ideas

**What is Storybook?** A widely used tool for previewing and documenting user-interface components one at a time,
each with live controls. Here it is our showroom and documentation.

**What is an A2UI component catalog?** A2UI is an open protocol that lets an AI agent describe a user interface as
JSON instead of writing code. A *catalog* is the list of components the agent is allowed to use, with the properties
each one accepts. The agent can only use what the catalog defines.

**Where do these components come from?** The **Basic Catalog** is provided by the **official A2UI SDK**. These are
**not** components our team wrote, and they were **not** exported from Storybook. We show them here so visitors can
see each building block and the A2UI messages that use it.

**How do agents use them?** The agent sends a JSON message that lists components and how they nest, for example a
card containing a row of text and a button. The app renders it with the official SDK. When the user clicks a button,
an event goes back to the agent, which can answer with a new message.

    <tr>

    </tr>
    <tr>
      <td><code>createSurface</code></td>
      <td>A structured A2UI JSON message that describes one piece of UI: which components to show, their properties, and how they are arranged.</td>
    </tr>
  </tbody>
</table>

## Good to know

- **The budget tracker uses deterministic sample logic, not a live AI model call.** Its responses are scripted so the
  demo is reliable and works offline. There is no dedicated budget component: the whole screen is one `createSurface`
  message made from Basic Catalog building blocks.
- **Our exporter is shown separately in a terminal.** It is a command-line tool that reads a Storybook build of *new*
  React components and writes an A2UI catalog definition for them. It did not produce the Basic Catalog.
